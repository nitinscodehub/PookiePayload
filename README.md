# PookiePayload 💗⚡

A lightweight Python automation script that repeatedly delivers any custom message you choose.

## Why PookiePayload?

Sometimes one message isn't enough.

Whether it's:

* "I love you" 💗
* "Sorry" 🥺
* "Good Morning" ☀️
* or any custom text

PookiePayload automates repetitive messaging through a simple Python implementation.

## Features

✔ Custom message support

✔ Easy to modify

✔ Lightweight and beginner-friendly

✔ Clean and readable code

✔ Perfect for learning automation concepts

## How It Works

1. Open the script.
2. Change the message text.
3. Run the program.
4. Watch the automation work.

## Requirements

* Python 3.x
